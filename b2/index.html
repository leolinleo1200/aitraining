WHAT MAKES A GOOD UI

好介面不是好看，是「好用」

介面服務流程

先問使用者要完成什麼，再決定畫面長什麼樣，不是反過來。

少即是清楚

一個畫面只承擔一個主要任務，別把功能全塞在同一頁。

一致就好用

一樣的東西長一樣、放一樣的位置，使用者就不用重新學。

WIREFRAME · 線框

線框先於美感：先排位置，不管顏色

線框稿 · 單字卡頁
  • 為什麼先畫：便宜、快、可以一直改；結構錯了，畫再漂亮也白搭。
  • 線框畫什麼：標題、內容、按鈕的「位置」，先用灰框，不放真實顏色與字體。
  • 最常見的錯：一開口就糾結顏色字型，把時間花在還會被打掉的地方。
  • 好處：帶著線框去跟 Stitch 說話，它一看就懂你要的結構。
WARM UP · AI 對話工具

動工具前，先用 AI 對話工具把話說順

碰 Stitch、AI Studio 之前，先用你順手的 AI 對話工具（GPT、Gemini 都可以）把需求生成一輪，把 prompt 練順。

為什麼先用它

免安裝、開瀏覽器就能用，生錯了重來也不心疼——最適合拿來練 prompt、抓感覺。

在這裡練什麼

把 User Flow、線框描述、要餵 Stitch 的 prompt、AI 例句與題目，先用一句話生出來、改順。

練好再搬家

滿意的內容再貼進 Stitch 生介面、AI Studio 接功能，少走冤枉路。

PROMPT 範例 · 複製即用

先貼進 AI 對話工具，生出來再改

下面四個 prompt 直接複製到你用的 AI 對話工具（GPT、Gemini 都可以），把 App 需要的東西一段一段生出來。

① 生 User Flow：
我在做一個背單字 App。請把使用者「學一輪」的動線，從打開 App 到看進度，一步步用 → 列出來，並標出答錯後進複習的分支。
② 生單頁線框：
請描述「單字卡頁」的線框：上／中／下各放什麼、有哪些按鈕，只寫結構與位置，先不要顏色和字體。
③ 生 Stitch 用的 prompt：
幫我把下面需求，整理成一段能丟給 Stitch 生手機介面的 prompt：
［貼上你的線框與必要元素］
④ 生例句與題目：
你是英語老師。用單字 abandon 生 3 個生活化例句（附中譯），再出 1 題四選一中文選擇題並標出正解，用 JSON 回傳。
MEET STITCH

認識 Stitch：用文字生介面

它是什麼

Google 推出的 AI 介面設計工具：用一段文字描述一個畫面，它就生出對應的 UI。

它能做什麼

生出畫面、產生多個版本、調整風格，並可匯出成程式碼或設計檔。

怎麼餵它

不是丟「幫我做 App」，而是把一頁的線框與需求描述給它，一頁一頁生。

STITCH PROMPT · 把線框餵給它

一次描述「一個畫面」，不是整個 App

畫面：單字卡頁（依我的線框）
使用者要做的事：看今天的單字、翻卡看解釋、標記已熟悉。
必要元素：單字、音標、詞性、中文解釋、例句、兩顆熟悉度按鈕。
版位：上方進度、中間單字卡、底部按鈕。
風格：乾淨、教育感、行動優先（手機版）。
GENERATE SCREENS

一頁一頁生：主要畫面清單

首頁

今日進度、開始今天的單字、繼續上次。

單字卡

單字、解釋、例句、翻卡、標記熟悉。

測驗頁

四選一、送出、即時對錯回饋。

複習頁

錯題清單、重新測驗、標記已熟悉。

進度頁

已學 / 待複習 / 已熟悉，數量與百分比。

設定頁

每日字數、提醒時間、中英解釋切換。

🔗 打開完整對照範例　六個畫面：需求 → Prompt → 線稿 → Stitch
REFINE & CONSISTENCY

調整版面，保持一致

改而不重生

不滿意就描述「改哪一塊、怎麼改」，不要整頁打掉重來。

定一套設計系統

主色、字級、間距、圓角固定下來，所有畫面共用。

元件重用

按鈕、卡片、標籤長一樣，換頁時使用者一眼就懂。

先手機再桌機

行動優先：小螢幕排得好，大螢幕通常也順。

GOOGLE AI STUDIO

認識 Google AI Studio

Stitch 負責「外觀」，但有些功能要真的用到 AI——那部分先在 AI Studio 試通。

它是什麼

Google 的線上實驗場，直接試用 Gemini 模型、調整 prompt，不用先寫程式。

在這個 App 做什麼

試「要用到 AI 的功能」：自動生成例句、AI 出題、AI 解釋單字。

和 Stitch 的分工

Stitch 做畫面、AI Studio 試 AI 功能，兩個拼起來才是完整的 App。

GOOGLE AI STUDIO · 實作

在 AI Studio 試出一個 AI 功能

  • 開 aistudio.google.com，用 Google 帳號登入。
  • 選 Gemini 模型，開一個新的 prompt。
  • 貼上任務 prompt，按執行看結果。
  • 調 temperature、長度，讓輸出穩定。
  • 滿意後用「Get code / API key」把它接進 App。
你是英語出題老師。
根據單字 abandon，出一題四選一中文選擇題：

・三個合理但錯誤的誘答

用 JSON 回傳。

先在 AI Studio 試通，再接進產品；API key 要收好、別外流。

WALK THE JOURNEY

模擬用戶體驗：自己走一遍

假裝你是第一次打開這個 App 的人，照 User Flow 從頭走一次。

  • 從打開 App，到完成一輪「學單字 → 測驗 → 看結果」。
  • 每一步都問自己：我現在知道要做什麼嗎？
  • 哪裡猶豫、哪裡點錯、哪裡不知道成功了沒——通通記下來。
  • 把卡點列成清單，這就是下一版要修的東西。
COMMON PITFALLS

常見卡點 & 怎麼修

資訊過載

一頁塞太多。留下主任務，其他收進次要位置或另一頁。

不知道點哪

主要按鈕（CTA）不明顯。一頁一個主行動，讓它最搶眼。

沒有回饋

做了不知道成功沒。加上狀態變化、提示、動畫。

路徑太長

要點太多次才到目的。把常用動作往前挪、減少步驟。
