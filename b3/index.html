SCENARIO DESIGN

什麼是「AI 場景設計」？

不是問一個問題就結束，而是把 AI 放進一個「會持續使用的情境」，事先設定好它的角色、任務、規則與邊界。

角色

它是誰？以什麼身分和使用者互動。

任務

它幫使用者完成什麼？服務目標是什麼。

規則

該怎麼回應、什麼時候糾正、什麼時候鼓勵。

邊界

不該做什麼、遇到不會的怎麼辦。

A BOT IS ITS PROMPT

聊天機器人，九成看它的指令

同一個 AI 模型，指令寫得好不好，決定它是專業教練還是答非所問。一份好的系統指令有五塊：

角色

它扮演誰、服務誰。

目標

每次互動要幫使用者達成什麼。

語氣

親切、簡短、鼓勵，還是嚴謹。

規則

怎麼教、怎麼糾錯、一次教多少。

拒絕邊界

不談無關的事、不確定就說不確定。

DEFINE THE BOT

設計單字教練 Bot：先定角色與任務

它是誰

一位耐心的英文單字教練，服務準備英檢與職場英文的成人。

它幫你做什麼

帶你複習今天的單字、用它造句、糾正用法與搭配。

它的個性

鼓勵、簡短、多給例子，不長篇大論，不打擊信心。

INSTRUCTION TEMPLATE

指令規劃模板

角色：你是一位耐心的英文單字教練，服務準備英檢與職場英文的成人學習者。
目標：幫使用者記住並會用今天的單字。
互動規則：一次只教一個單字；先給例句，再請對方造句；答對稱讚，答錯溫和糾正並再給一個例子。
語氣：親切、簡短、鼓勵；用繁體中文解釋，用英文示範。
邊界：只談英文學習；不確定時說不確定，不要編造。
TEACHING TECHNIQUES

讓 Bot 真的會教，幾個技巧

循序漸進

由易到難，先熟悉再進階，別一次丟一堆。

給真實例句

用生活與職場情境造句，比背解釋好記。

即時糾錯

指出錯在哪，並給出正確用法，不要只說「錯了」。

控制難度

依對方回答的程度，動態調整下一題深淺。

正向回饋

答對給肯定，讓人有動力繼續下一個。

收斂範圍

聚焦今天的單字，不岔題、不無限發散。

TEST & TUNE

測試與調教 Bot

指令寫完一定要「找碴」，好的 Bot 是測出來、改出來的。

  • 給刁鑽輸入：答非所問、亂打字、故意拼錯，看它怎麼接。
  • 試著讓它越界：問和英文無關的事，看它會不會被帶走。
  • 檢查會不會編造：問它不確定的字義，看它敢不敢說不確定。
  • 根據結果回頭改指令，迭代 2–3 次再定稿。
QUIZ · QUESTION TYPES

英語教學測驗：先選題型

四選一

認得字義。最快、最好判分，適合第一版。

填空

會拼、會在句子裡用，比選擇更扎實。

句子重組

練語序與搭配，檢查是否真的會用。

聽力 / 口說

進階題型，接發音與語音辨識，之後再加。

BUILD THE QUIZ

測驗實作：出題 → 判分 → 回饋

出題

從單字資料挑題，設定題數與難度，錯誤選項要合理。

→

判分

即時判斷對錯，記錄錯題與作答時間。

→

回饋

解釋為什麼錯、給正確用法，把錯題丟回複習。

這一組「出題 / 判分 / 回饋」的邏輯，正是 B1 藍圖裡的「邏輯層」。
